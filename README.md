# การวิเคราะห์ปัจจัยที่เกี่ยวข้องกับความรุนแรงของการบาดเจ็บจากอุบัติเหตุช่วงเทศกาลสงกรานต์

## 1. เกี่ยวกับโครงงาน

โครงงานนี้จัดทำขึ้นเพื่อวิเคราะห์ปัจจัยที่เกี่ยวข้องกับความรุนแรงของอุบัติเหตุในช่วงเทศกาลสงกรานต์ โดยพิจารณาข้อมูลของผู้ประสบเหตุทั้งผู้ที่ไม่เสียชีวิตและผู้เสียชีวิต และนำเสนอผลการวิเคราะห์ในรูปแบบ Interactive Data Visualization ผ่านเว็บไซต์ เพื่อให้สามารถสำรวจและเปรียบเทียบข้อมูลได้ง่ายและเข้าใจได้ชัดเจนมากขึ้น

ข้อมูลที่นำมาวิเคราะห์ประกอบด้วยปัจจัยต่าง ๆ เช่น จังหวัด วันที่และเวลาเกิดเหตุ เพศ อายุ ถนนที่เกิดเหตุ ประเภทรถ การดื่มสุรา และผลการรักษา โดยใช้ `ผลการรักษา` เป็นข้อมูลหลักในการพิจารณาระดับความรุนแรง แบ่งเป็น **เสียชีวิต** และ **ไม่เสียชีวิต**

เว็บไซต์พัฒนาด้วย HTML, CSS และ JavaScript โดยใช้ **Chart.js และ D3.js** ในการสร้าง Visualization

## 2. วัตถุประสงค์

-	วิเคราะห์ปัจจัยที่เกี่ยวข้องกับความรุนแรงของการบาดเจ็บ
-	ศึกษาความสัมพันธ์ระหว่างปัจจัยต่าง ๆ กับผลการรักษา
- นำเสนอข้อมูลเพื่อให้เข้าใจลักษณะและแนวโน้มของการบาดเจ็บในช่วงเทศกาลสงกรานต์

## 3. ชุดข้อมูล

## 4. รูปแบบการนำเสนอข้อมูล

### 4.1 Bar Chart — ผลการรักษา

ใช้แสดงจำนวนผู้ประสบเหตุตามผลการรักษา เพื่อให้เห็นจำนวนของแต่ละผลลัพธ์ และใช้ประกอบการวิเคราะห์ความรุนแรงของอุบัติเหตุ

### 4.2 Doughnut Chart — ระดับความรุนแรง

ใช้แสดงสัดส่วนระหว่าง **ผู้เสียชีวิตและผู้ไม่เสียชีวิต** เพื่อให้เห็นภาพรวมของระดับความรุนแรงของอุบัติเหตุ

### 4.3 Bar Chart — 10 จังหวัดที่มีผู้ประสบเหตุสูงสุด

ใช้เปรียบเทียบจำนวนผู้ประสบเหตุในแต่ละจังหวัด และแสดง 10 จังหวัดที่มีจำนวนสูงสุด เพื่อดูพื้นที่ที่มีผู้ประสบเหตุมาก

### 4.4 Line Chart — จำนวนผู้ประสบเหตุตามชั่วโมง

ใช้แสดงจำนวนผู้ประสบเหตุตั้งแต่เวลา 00:00–23:00 น. เพื่อดูช่วงเวลาที่เกิดเหตุจำนวนมากหรือน้อย

### 4.5 Grouped Bar Chart — ผู้เสียชีวิตและไม่เสียชีวิตตามเทศกาล

ใช้เปรียบเทียบจำนวน **ผู้เสียชีวิตและไม่เสียชีวิตในแต่ละเทศกาล** โดยแสดงเป็นแท่งคู่ข้างกัน เพื่อให้เห็นความแตกต่างของระดับความรุนแรงในแต่ละปี

### 4.6 Doughnut Chart — ผู้ประสบเหตุตามเพศ

ใช้แสดงสัดส่วนของผู้ประสบเหตุจำแนกตามเพศ เพื่อศึกษาความแตกต่างของผู้ประสบเหตุระหว่างเพศ

### 4.7 Bar Chart — การดื่มสุรา

ใช้แสดงจำนวนผู้ประสบเหตุจำแนกตามข้อมูลการดื่มสุรา เพื่อศึกษาความเกี่ยวข้องระหว่างพฤติกรรมการดื่มสุรากับความรุนแรงของอุบัติเหตุ

### 4.8 Choropleth Map — แผนที่ประเทศไทย

ใช้แสดงการกระจายของ **ผู้เสียชีวิตตามจังหวัด** บนแผนที่ประเทศไทย โดยใช้สีในการแสดงระดับจำนวนผู้เสียชีวิตของแต่ละจังหวัด และสามารถเลื่อนเมาส์เพื่อดูรายละเอียดของจังหวัดได้

## 5. การโต้ตอบกับข้อมูล

เว็บไซต์รองรับการโต้ตอบกับข้อมูล ได้แก่

- **Filter** — กรองข้อมูลตามเทศกาล จังหวัด เพศ และการดื่มสุรา
- **Tooltip** — แสดงรายละเอียดของข้อมูลเมื่อเลื่อนเมาส์ไปยังกราฟหรือแผนที่
- **Interactive Map** — สามารถเลื่อนเมาส์ไปยังจังหวัดเพื่อดูข้อมูล
- **Animation** — เพิ่มการเคลื่อนไหวในการแสดงผลกราฟ เพื่อให้การนำเสนอข้อมูลน่าสนใจมากขึ้น

เมื่อผู้ใช้เปลี่ยนตัวกรอง ระบบจะปรับปรุงข้อมูลสรุปและ Visualization ให้สอดคล้องกับข้อมูลที่เลือก
